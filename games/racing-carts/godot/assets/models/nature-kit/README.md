# Nature Kit (Kenney)

- Pack: Nature Kit 2.1 by Kenney, https://kenney.nl/assets/nature-kit
- Licence: Creative Commons CC0 1.0 (public domain), see `License.txt`.
- Used: three trees, a bush, two stones, three flowers, a fence and a lily pad, for the track dressing
  (`scenes/scenery/`). The import settings remap their materials to the pastel ones in `scenes/scenery/materials/` and
  save each mesh to `scenes/scenery/meshes/`, which the scenery's MultiMeshes use.
